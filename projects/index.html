შესრულებული პროექტები

აქ წარმოდგენილია ჩემ მიერ შექმნილი ვებ-აპლიკაციები და პრაქტიკული პროექტები:

Project 01 🌸

1. ელექტრონული კომერციის პლატფორმა (E-Commerce)

სტატუსი: დასრულებული თარიღი: ნოემბერი 2025

სრულყოფილი ონლაინ მაღაზიის სისტემა, რომელიც მოიცავს პროდუქციის კატალოგს, დინამიკურ ფილტრაციას, კალათის ფუნქციონალს და შეკვეთის გაფორმების პროცესს.

ძირითადი ფუნქციონალი:

  • 🌸 პროდუქციის კატალოგის დათვალიერება და კატეგორიზაცია;
  • 🌸 საძიებო სისტემა და ფილტრები ფასისა და რეიტინგის მიხედვით;
  • 🌸 მომხმარებლის ავტორიზაცია და პირადი კაბინეტი;
  • 🌸 ინტერაქტიული კალათა (Shopping Cart) და შეკვეთის გაფორმება.

გამოყენებული ტექნოლოგიები:

  • HTML5 — სემანტიკური მარკირება და ხელმისაწვდომობა (a11y)
  • CSS3 — ადაპტური დიზაინი (Flexbox, Grid)
  • JavaScript — კლიენტის ლოგიკა და მონაცემთა მანიპულაცია
  • LocalStorage API — კალათის მონაცემების შენახვა
დამატებითი დეტალები პროექტის შესახებ

პროექტი ოპტიმიზებულია მობილური მოწყობილობებისთვის და სრულად შეესაბამება თანამედროვე ვებ-სტანდარტებს.

Project 02 🌷

2. დავალებების მმართველი (Task Manager)

სტატუსი: დასრულებული თარიღი: აგვისტო 2025

პროდუქტიულობის ასამაღლებელი აპლიკაცია, რომელიც მომხმარებლებს საშუალებას აძლევს დაგეგმონ, მართონ და გადაანაწილონ ყოველდღიური დავალებები პრიორიტეტების მიხედვით.

ძირითადი ფუნქციონალი:

  • 🌸 დავალებების დამატება, რედაქტირება და წაშლა (CRUD);
  • 🌸 სტატუსების მართვა (შესასრულებელი, მიმდინარე, დასრულებული);
  • 🌸 პრიორიტეტების მინიჭება და გაფილტვრა;
  • 🌸 მონაცემთა ავტომატური დამახსოვრება ბრაუზერში.

გამოყენებული ტექნოლოგიები:

  • HTML5 — ფორმები და სემანტიკური სტრუქტურა
  • JavaScript (ES6+) — დინამიკური DOM მანიპულაცია და ივენთები
  • LocalStorage API — მონაცემთა ლოკალური პერსისტენტულობა
ბმულები:

Project 03 🌺

3. ამინდის პროგნოზის აპლიკაცია (Weather App)

სტატუსი: დასრულებული თარიღი: აპრილი 2025

ინტერაქტიული აპლიკაცია, რომელიც იყენებს გარე API-ს და მომხმარებელს აწვდის რეალურ დროში მიმდინარე ამინდისა და 5-დღიანი პროგნოზის ინფორმაციას მსოფლიოს ნებისმიერი ქალაქისთვის.

ძირითადი ფუნქციონალი:

  • 🌸 ქალაქის მიხედვით ძიება ავტოშევსების მხარდაჭერით;
  • 🌸 ტემპერატურის, ტენიანობის, ქარის სიჩქარისა და წნევის ჩვენება;
  • 🌸 დღისა და კვირის დეტალური პროგნოზი;
  • 🌸 მომხმარებლის გეოლოკაციის ავტომატური ამოცნობა.

გამოყენებული ტექნოლოგიები:

  • HTML5 — სემანტიკური ელემენტები
  • JavaScript — Fetch API, Asynchronous JS (async/await)
  • OpenWeatherMap REST API — მონაცემთა წყარო
